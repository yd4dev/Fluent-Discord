# Fluent Discord
A Windows 11 theme for Discord

## Download
* From [Releases](https://github.com/TakosThings/Fluent-Discord/releases/latest)
  * `Fluent-Discord.theme.css` will automatically update with new releases
  * `Fluent-Discord-static.theme.css` if you prefer to manually update to each release
* [Github.io link](https://takosthings.github.io/Fluent-Discord/Fluent-Discord.theme.css) (Right-click > Copy Link)

### Optional Extras
* [EmojiReplace](https://betterdiscord.app/theme/EmojiReplace) theme by DevilBro to get Windows 11 emoji on Discord

## Creating a Release
Releases are published manually via the **make-release** GitHub Actions workflow:

1. Go to **Actions → make-release → Run workflow**.
2. Enter a version tag in the format `vX.Y.Z` (e.g. `v1.3.0`).
3. Click **Run workflow**.

The workflow will build both theme files, create a git tag, publish a GitHub Release with the CSS files attached, and deploy the auto-updating theme to GitHub Pages.
